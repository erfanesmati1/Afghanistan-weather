What Data This App Uses

Plain-language data inventory

Data this app stores in your browser

  • Language and appearance preference.
  • Selected city or province and its coordinates.
  • Open-Meteo weather response values and a cache timestamp.

Storage is local to the browser profile. The app does not send those preferences to its own server because this project has no application backend.

Data sent to Open-Meteo

  • A global place name you type is sent to the Geocoding API. The app does not retain the typed query.
  • Coordinates for the chosen place are sent to the Forecast API.
  • If you explicitly choose browser location, your coordinates are sent to the Forecast API to return local weather.

These requests also travel with ordinary network metadata. Open-Meteo receives requests directly from the browser, so this app operator does not proxy or control provider logs. See Open-Meteo’s current privacy information.

Data this app does not request

No name, email, phone number, password, payment details, contacts, photos, documents, or account identifier is requested. There is no analytics SDK, ad tracker, user-upload form, or embedded third-party widget.

Deleting browser data

Remove this site’s local storage in browser settings to clear saved preferences, location, and cached weather. The app cannot delete technical logs retained independently by Open-Meteo or the selected hosting provider.
